# Build plan

## Phase 1 — foundation
- Independent GitHub repository and static landing page
- Confirm branding, domain, and legal business entity
- Verify every external resource URL and eligibility claim
- Publish privacy policy and terms after legal review

## Phase 2 — working marketplace
- Next.js / TypeScript frontend
- Supabase PostgreSQL and Auth, with row-level security
- Housing and employment opportunity tables
- Employer / landlord submission portal and admin moderation
- Saved opportunities, applications and referral consent
- Anti-fraud reporting and expiration checks

## Phase 3 — record relief
- Private browser-only screening flow
- Ohio statute rules stored as versioned data
- Attorney review and tests before eligibility calculations are released
- No sharing with employers or landlords

## Launch gates
- Security and access-control tests
- Verified source and freshness for every opportunity
- Legal and fair-housing review
- Accessibility and mobile testing
- Honest disclosure of pilot status
